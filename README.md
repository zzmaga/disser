# KazStyle

Определение пяти функциональных стилей казахского текста. Локальный сайт,
подготовка корпуса и воспроизводимое сравнение моделей для магистерской диссертации.

**[Результаты и рукопись](reports/PROJECT_STATUS.html)** ·
**[Состояние проекта, решения и следующие задачи](docs/PROJECT.md)**

## Запуск

Дважды нажмите `start_site.cmd`, затем откройте **http://127.0.0.1:8765**.
Можно вставить текст и сравнить шесть обученных моделей. Внешний ИИ API не используется.

```powershell
.venv/Scripts/python.exe manage.py serve
```

Активные модели заданы в `configs/deployment.json`; нужны локальные данные
`data/processed/text_only_v4_shared/` и четыре каталога весов в `artifacts/`.
Данные и веса не входят в Git. Сайт явно показывает прочитанный фрагмент длинного текста.

## Где что лежит

| Путь | Назначение |
| --- | --- |
| `AGENTS.md` | Короткие инструкции для следующего агента |
| `docs/PROJECT.md` | Единственный актуальный паспорт и история важных решений |
| `docs/WORKFLOW.md` | Архитектура, команды и правила хранения |
| `docs/GPU.md` | Проверенное окружение и обучение на видеокарте |
| `kazstyle/`, `frontend/` | Код и интерфейс |
| `configs/` | Источники, планы экспериментов, зависимости, активный профиль |
| `data/` | Исходные данные, кандидаты, версии корпуса и разметка |
| `artifacts/` | Только четыре каталога активных весов сайта |
| `reports/` | Актуальные результаты; начать с `PROJECT_STATUS.html` |
| `reports/technical/` | Логи и технические доказательства |
| `archive/` | Остальные seed, старые модели, отчёты и заметки |
| `models/` | Предобученные ресурсы морфологической обработки |
| `tests/` | Проверки данных, моделей, архивного доступа и HTTP |

Архивирование упорядочивает проект, но не освобождает место и не является резервной
копией. Для чтения прежних запусков код поддерживает `archive/artifacts/`.
Правила сохранения и удаления описаны в [WORKFLOW](docs/WORKFLOW.md).

## Дальнейшая работа

Расширенный корпус v6 содержит 1 265 текстов, по 253 на стиль. Сравнение шести
вариантов с тремя seed завершено; отдельно проверены новые источники и длина текста.
V6 пока не заменяет основной сайт: обнаружена регрессия на школьном заявлении.
Для новых весов есть отдельный профиль `configs/deployments/expanded_v6_shared.json`
и экспериментальный порт 8766. Следующий этап — независимая человеческая проверка
меток и деловых жанров, затем финальная оценка. Готовность всей диссертации не заявляется.
Подробности и ссылки на формы: [паспорт проекта](docs/PROJECT.md).
