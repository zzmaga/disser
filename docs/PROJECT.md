# Паспорт проекта KazStyle

Обновлено: 2026-10-10. Это краткая постоянная память для владельца и новых агентов.
Подробные доказательства лежат по указанным путям; читать весь архив не требуется.

## Цель и границы

Тема из ИПМ: **«Построение корпуса и разработка системы определения текстового стиля
на казахском языке с использованием методов машинного обучения»**.
Пользователь хочет завершить работу примерно за месяц. Сейчас приоритет — качество
корпуса и подтверждённые эксперименты. Сайт уже служит инструментом проверки.
Пять классов: Formal, Scientific, Publicist, Artistic, Colloquial.
Генерация и перенос стиля (GAN/style transfer) не входят в основную задачу.

## Что работает сейчас

- Переносимый пример очистки: `python -m kazstyle.demo --out-dir build/demo`.
  Пять искусственных записей дают 3 сохранённых текста, исключаются повтор и пустой текст.
  Это проверка кода, не модель и не исследовательский корпус. `scripts/ci.py` запускает
  14 тестов без весов и данных; локально прошли также в отдельной чистой копии исходников.
  GitHub Actions: `.github/workflows/ci.yml`, Ubuntu/Windows, Python 3.12, push/PR/manual.
  Актуальный результат: https://github.com/zzmaga/disser/actions/workflows/ci.yml.
  Публикация сайта и новых весов на сервере не настроена.
- Сайт: `start_site.cmd` → http://127.0.0.1:8765. Кнопка «Сравнить все» запускает
  шесть локальных моделей. Внешний ИИ API не используется.
- Профиль: `configs/deployment.json`; корпус: `data/processed/text_only_v4_shared/`.
- 610 фиксированных фрагментов: 122 на класс, train 370, validation 120, test 120.
  У всех моделей один и тот же текст, совместимый с двумя токенизаторами.
- Три линейных варианта: TF-IDF слов + LR, TF-IDF слов + SVM, TF-IDF символов + SVM.
  Три нейросетевых: mBERT, Kaz-RoBERTa last, Kaz-RoBERTa concat4.
- Каждый вариант обучен с seed 42/43/44; нейросети — две эпохи, effective batch 8.
  Основная модель — Kaz-RoBERTa last, выбрана по среднему validation. Сайт использует

  Школьное заявление: 5 → Formal, character SVM → Publicist.

  На тех же 610 фрагментах сравнивались raw / stanza_surface / stanza_lemma с LR/SVM.
  Устойчивое улучшение не установлено: validation ниже, интервалы разницы включают ноль.
  POS и морфологические признаки сохранены, но не используются основной шестёркой.
  Источник: `archive/reports/morphology_ablation_v1/`; план: `configs/experiment_morphology_v1.json`.

  mBERT/Kaz-RoBERTa прошли проверочные эпохи и восстановление на CPU. Для 4 ГБ:

## Принятые решения и следующий этап

1. Сначала улучшить корпус: проверить метки и новые кандидаты, расширить источники и
   жанры. Приоритетны естественное разговорное общение, научные тексты, заявления/
   договоры и проза разных авторов. Равное количество плохих текстов не решает задачу.
2. Хранить происхождение; группировать перепечатки, один документ/произведение/цепочку
   сообщений до разбиения. Недостаток класса не компенсировать копиями или произвольной
   нарезкой одного документа на независимые наблюдения.
3. V6 уже заморожена после исправления общих фрагментов. Следующую версию строить после
   содержательной проверки меток и новых независимых источников, а не ради большей цифры.
4. Основная серия `configs/experiment_expanded_v6.json` завершена: все 12 заданий,
   исходные веса и seed 42/43/44 фиксированы. Не повторять серию при каждом CSV.
   Сначала независимая проверка меток, жанров и регрессии деловых текстов.
5. Классические модели обучать заново вместе с TF-IDF; нейросетевые сравнения начинать
   с одинаковых исходных предобученных encoder. Продолжение старых весов — отдельный
   эксперимент, не незаметная замена процедуры. Перестановка файлов без изменения
   текстов/меток не требует переобучения.
6. Финальную оценку провести на отдельно проверенных новых источниках. Известные
   пользовательские и веб-примеры оставить регрессионными. После этого завершить
   обсуждение, выводы, оформление и доклад.
