# Фактические результаты нового пилота

25 сентября 2026 года выполнены новые запуски после замены старого обучения и
предобработки. Это реальные локальные результаты, не числа из статьи. Все модели
получили одну версию данных и одно фиксированное разбиение.

## Данные

Три класса: официально-деловой, публицистический, художественный. По 300 документов
каждого класса; всего 900. На класс: 210 train, 45 validation, 45 test. Итого 630,
135 и 135 соответственно. Один центральный фрагмент на документ; максимум 160 слов
и 256 токенов Kaz-RoBERTa. Среди 900 фрагментов 288 потребовали дополнительного
ограничения по токенам. Один и тот же итоговый текст подаётся всем моделям.

CSV проверены строгим парсером: длинные строки и корректно заключённые в кавычки
переносы не являются ошибками. В official.csv найдены 4 документа с внутренними
переносами; они прочитаны целиком. Девять слишком длинных документов выбранных
классов отложены для проверки, один — по языковой эвристике. Исходные файлы сохранены.

## Результаты

| Модель | Validation Macro-F1 | Test Macro-F1 | Test accuracy |
|---|---:|---:|---:|
| Dummy (частотный контроль) | 0.1667 | 0.1667 | 0.3333 |
| TF-IDF слов + Logistic Regression | 0.9853 | 0.9779 | 0.9778 |
| TF-IDF слов + LinearSVC | 0.9778 | 0.9853 | 0.9852 |
| TF-IDF символов + LinearSVC | 0.9852 | 0.9852 | 0.9852 |
| Kaz-RoBERTa, последний слой | 0.9852 | 1.0000 | 1.0000 |
| Kaz-RoBERTa, четыре последних слоя | 0.9852 | 1.0000 | 1.0000 |

Классические конфигурации зафиксированы до test; TF-IDF обучался только на train.
Обе нейросети обучались по 2 эпохи на CPU, batch_size=8, lr=2e-5, seed=42, 4 потока.
Лучшая эпоха выбиралась по validation, после чего test проверялся один раз. Разброс
между несколькими seed ещё не оценён. Сохранены предсказания каждого примера.

## Что результаты означают

Рабочий цикл подготовки данных, обучения, оценки и сохранения моделей восстановлен.
В pilot-тесте разделены документы, точные тексты и найденные группы близких повторов.
Проверка загрузки сохранённых моделей выполнена; для нейросетей — offline из config
и checkpoint. Семь автоматических проверок обработки данных проходят.

Высокий F1 не доказывает перенос на новые сайты: каждый из трёх классов всё ещё
происходит из своего сайта. Контрольное правило, которое использует только домен
источника и вообще не читает текст, получает Macro-F1=1.0. Это показывает ограничение
корпуса, а не устанавливает, какие признаки использовала нейросеть.

Метки получены из источников, ручная проверка ещё не проведена. Подготовлены 60
примеров train и инструкция для проверки. Нельзя заявлять, что весь корпус прошёл
экспертную валидацию. Результаты этого трёхклассового пилота не воспроизводят
пяти-классовые числа статьи и не должны подменять их.

## Дополнительные данные

Проверен MDBKD на Hugging Face. В нём нет готовых функциональных меток. В начале
kazakhNews.csv просмотрено 8 977 записей в пределах 30 МиБ: все помечены rus и
отклонены. Из kazakhBooks получено 10 кандидатов; среди просмотренных начал есть
учебные пособия и OCR-шум. Они сохранены отдельно, без стилевой разметки и без
включения в обучение. Полный корпус не скачивался.

## Следующий этап

Проверить метки, добавить независимые источники каждого стиля, исправить общую
квоту старых сборщиков на квоты по источникам. После этого зафиксировать новый
корпус и внешний тест, повторить сравнение с несколькими seed. Scientific и
Colloquial включить после отдельной проверки. LLM API можно добавить позднее
как ещё один baseline на том же тесте с учётом цены и задержки.
