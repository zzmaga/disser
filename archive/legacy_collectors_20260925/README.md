# Старые сборщики

Исходные сборщики и настройки источников перенесены сюда без изменения содержимого.
Текущий сайт и обучение их не вызывают. Сборщики нужно пересмотреть перед новым сбором:
квоты должны учитывать разные источники каждого стиля, а новые данные проходить ручную проверку.
Сохранены в Git как исходный код; старые веса, корпуса и временные файлы архива исключены.
