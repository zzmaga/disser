# Холодный архив

Эту папку не нужно читать при обычной работе. Актуальный статус — `docs/PROJECT.md`,
активные веса — в `artifacts/`, актуальные результаты — в `reports/`.

- `artifacts/`: остальные seed основной серии, старые модели и инженерные GPU-проверки.
  Каждый запуск хранится целиком: веса, параметры, предсказания и исходный код.
- `reports/`: прежние отчёты и заменённые черновики рукописи.
- `docs/`: прежние инструкции и исследовательские заметки. Они могут противоречить
  текущему состоянию; это история, а не действующие указания для агента.
- `reorganization_20261006/manifest.json`: старые и новые пути, размеры и SHA-256
  939 перенесённых файлов. `verification.json` подтверждает проверку переноса.
  `link_repairs.json` отдельно фиксирует исправление ссылок в двух HTML-отчётах.
- `reorganization_20261006/expanded_manifest.json`: ещё 1 678 файлов в 31 каталоге,
  включая исследовательские веса v6 и исторические отчёты v4. Контрольные суммы
  проверены в `expanded_verification.json`; удалений нет. Исследовательский профиль
  v6 читает эти веса из архива, основной сайт продолжает использовать v4.
- Папки с датой 20260925: история первой реорганизации, старые сборщики и эксперименты.

При чтении модели `artifact_path(run_id)` ищет её сначала в активном хранилище,
затем здесь. Две копии одного run ID запрещены: это было бы неоднозначно.
Снимки исходников внутри запусков не редактируются при изменении текущего кода.

## Что хранить

Повторы с seed 43/44 основной серии подтверждают сравнение из трёх запусков.
Старые завершённые эксперименты сохраняют историю исследовательских решений.
Их нельзя называть мусором только потому, что сайт не загружает эти веса.

## Что можно убрать при необходимости освободить место

Веса `gpu_pipeline_check_*` и `text_only_v3_roberta_concat4_interrupted_20261002`
не нужны для сайта и основной серии. Это первые кандидаты на удаление после
адресной проверки ссылок; текстовые отчёты и параметры следует сохранить.
В этой реорганизации файлы не удалялись. Повреждённый/прерванный запуск не
используется как результат завершённого обучения.

Архив находится на том же диске: это порядок хранения, а не независимая резервная
копия. Перенос на другой диск/внешнее хранилище — отдельная операция с проверкой
контрольных сумм и обновлением расположения.

Текстовые исторические заметки и реестр этой реорганизации не исключены из Git.
Веса, сырые данные и массивные отчёты по-прежнему локальные; новый клон репозитория
сам по себе их не восстанавливает.
