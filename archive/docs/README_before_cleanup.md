# KazStyle — определение стиля казахского текста

Локальный проект для магистерской диссертации: подготовка корпуса, обучение,
сравнение моделей и сайт для проверки текстов. Пять стилей: официально-деловой,
научный, публицистический, художественный, разговорный. Внешний ИИ API не используется.

## Открыть результаты и сайт

**[reports/PROJECT_STATUS.html](reports/PROJECT_STATUS.html)** — общая страница:
сравнение моделей, ошибки, разбор ИПМ и рабочая рукопись.

Дважды нажмите **start_site.cmd**, затем откройте **http://127.0.0.1:8765**.
«Сравнить все» показывает ответы шести моделей и точный прочитанный фрагмент.
Длинный текст сокращается с явным уведомлением.

```powershell
.venv/Scripts/python.exe manage.py serve
.venv/Scripts/python.exe manage.py predict --text-file example.txt --compare
```

Активный профиль: `configs/deployment.json`; проверенная копия:
`configs/deployments/text_only_v4_shared.json`. Нужны локальный корпус
`data/processed/text_only_v4_shared/` и каталоги весов:

- `artifacts/text_only_v4_classical_s42/` — три линейных классификатора;
- `artifacts/text_only_v4_mbert_last_s42/`;
- `artifacts/text_only_v4_kaz_roberta_last_s42/`;
- `artifacts/text_only_v4_kaz_roberta_concat4_s42/`.

Данные и веса не входят в Git. Старые версии сохранены для воспроизводимости.

## Что обучено

| Модель | Признаки |
| --- | --- |
| Logistic Regression | TF-IDF слов |
| Linear SVM | TF-IDF слов |
| Linear SVM | TF-IDF символов |
| mBERT | Дообучение multilingual BERT и классификационной головы |
| Kaz-RoBERTa | Представление последнего слоя |
| Kaz-RoBERTa concat4 | Объединение четырёх последних слоёв |

TF-IDF представляет текст числами, классификатор учится по этим признакам.
Предобученные encoder дообучаются вместе с головой; языковые модели с нуля не создаются.
В серии `text_only_v4` каждый вариант обучен с seed 42, 43 и 44. Нейросети — по две эпохи,
эффективный batch size 8. Основная модель выбирается по среднему **validation Macro-F1**.
На сайт подключаются заранее определённые варианты с seed 42.

[Отчёт сравнения](reports/text_only_v4_repeated/report.html) содержит точные числа,
все повторы и условные интервалы bootstrap. У каждого запуска сохранены веса,
предсказания, параметры, версии библиотек и снимок исходного кода.

## Данные и ограничения

- Исходный очищенный пул: **13 408 кандидатов** с предварительными метками.
- Общая выборка: **610 текстов**, по **122 на стиль**; 370 train, 120 validation, 120 test.
  Документы и группы повторов между частями не пересекаются; строки не размножаются.
- Все модели получают один и тот же очищенный фрагмент, помещающийся в ограничения
  обоих токенизаторов. В обучающих CSV только `text,label`. URL и происхождение
  хранятся отдельно; ссылки не являются признаками.
- Дополнительно собраны **276 кандидатов**: 120 научных аннотаций, 96 форумных вопросов,
  60 публикаций прозы. Они ещё не включены в обучение. Ещё 30 публикаций смешанного
  раздела прозы отправлены в карантин.

Корпус пока не прошёл независимую экспертную разметку. Источник и длина связаны со
стилем; высокие внутренние метрики не доказывают качество на произвольном тексте.
Внутренний test уже просматривался при разработке. Корпус на 22 600 документов и
готовность всей диссертации не заявляются.

[Твои примеры и замены имён/дат](reports/text_only_v4_user_diagnostics/report.html) ·
[14 известных веб-примеров](reports/web_probe_v4_20261006/report.html) ·
[Влияние признаков линейных моделей](reports/text_only_v4_linear_audit/report.html).
Это диагностика известных ошибок, а не окончательный внешний test.

Отдельно выполнена [проверка лемматизации](reports/morphology_ablation_v1/report.html):
Stanza обработала все 610 фрагментов; LR и SVM сравниваются на исходном тексте,
словоформах после сегментации и леммах. Устойчивое улучшение не установлено.
Морфологические признаки и POS сохранены для аудита; основной сайт их не использует.
[Обновлённое выполнение всех задач ИПМ](reports/ipm_progress_20261006.html).

## Следующий этап

Подготовлены [форма A](data/annotation/corpus_audit_20261006/reviewer_A.html) и
[форма B](data/annotation/corpus_audit_20261006/reviewer_B.html) для независимого аудита
250 текстов. Два человека заполняют их самостоятельно; источники и ответы моделей скрыты.
`annotate compare` и `annotate finalize` проверяют ответы, считают согласие,
сохраняют разрешённые разногласия и создают набор проверенных показанных фрагментов.
Человеческие ответы пока не получены.

После проверки меток: окончательное разбиение, отдельная проверка на новых источниках,
повторное обучение и завершение рукописи по требованиям университета.
[Разбор ИПМ и старого плана](reports/dissertation_audit_20261006/report.html).
